# 接口约定

本文件记录各页面可调用的数据接口与页面注册约定，供结对双方与测试人员参考。

## 全局对象

脚本加载顺序：`core.js` → `storage.js` → `app.js` → `pages/*.js`，均不使用 ES module。

| 全局对象 | 来源 | 说明 |
| --- | --- | --- |
| `Core` | js/core.js | 纯数据规则，不访问 DOM / localStorage，可在 Node.js 中 require |
| `Storage` | js/storage.js | 数据仓库工厂 |
| `App` | js/app.js | 导航、共用渲染与页面注册 |

## Core（数据规则）

- `Core.CATS`：物品分类表（8 类，含 label 与 emoji）
- `Core.LOCATIONS`：预设地点列表（11 个）
- `Core.validatePost(form)` → `{ ok, errors }`：标题 / 地点 / 联系方式必填，超长与非法分类拒绝
- `Core.createItem(form, type, ownerId, now?)` → `{ ok, item } | { ok:false, errors }`
- `Core.searchItems(items, { query, category, type, onlyActive })` → 过滤后的新数组
- `Core.sortItems(items)` → 进行中在前，同状态按日期新到旧
- `Core.toggleStatus(item, requesterId)` → `{ ok, item } | { ok:false, error }`，不修改原对象
- `Core.resolvedLabel(item)` / `Core.resolveActionLabel(item)`：寻物“已找到”，招领“已归还”
- `Core.escapeHtml(s)` / `Core.fmtDate(d)` / `Core.isValidItem(it)`

## Storage（持久化）

`Storage.createStore(backend?)` 创建仓库；浏览器默认使用 localStorage（键 `campus-lostfound.v1`），不可用时退化为内存后端。

- `store.load()` → 全部信息（首次或数据损坏时回退演示数据，坏记录逐条过滤）
- `store.add(item)` → `{ ok } | { ok:false, error }`
- `store.toggle(id, requesterId)` → 切换状态，带发布者权限校验，写入失败自动回滚
- `store.getClientId()` → 本浏览器标识（`cid-` 前缀），用于区分“我发布的”
- `store.reset()` → 清空数据

演示数据 `ownerId` 固定为 `'demo'`，不会出现在任何浏览器的“我的发布”。

## App（页面与导航）

- `App.registerPage(name, renderFn)`：注册页面，`renderFn(rootEl)` 负责渲染 `#view`
- `App.goTab('home' | 'post' | 'search' | 'mine')`：切换底部导航
- `App.openDetail(id, from)`：进入详情，`from` 用于返回定位（home / search / mine / success）
- `App.goBack()`：按 `from` 返回进入详情前的页面，搜索条件保留
- `App.toggleStatus(id)`：状态更新统一入口（含 toast 反馈与重渲染）
- `App.copyContact(text)`：复制联系方式，两级降级，不谎报成功
- `App.cardHtml(item)` / `App.bindCards(root, from)`：列表卡片共用渲染器与点击绑定
- `App.state`：当前 UI 状态（视图、筛选、表单等）；数据本体永远在 `App.store` 里

## 数据模型

```js
{
  id: 'p…',            // createItem 生成
  type: 'lost' | 'found',
  category: 'card' | 'keys' | 'bottle' | 'umbrella' | 'headphones' | 'book' | 'bag' | 'other',
  title: String,       // ≤ 30 字
  description: String, // ≤ 200 字，可空
  location: String,    // 必须属于 Core.LOCATIONS
  date: 'YYYY-MM-DD',  // 本地时区
  contact: String,     // ≤ 50 字
  poster: String,      // 用户发布固定为“我”
  status: 'active' | 'resolved',
  ownerId: String,     // 发布者 clientId；演示数据为 'demo'
}
```

所有来自用户输入的字符串在写入 HTML 前必须经 `Core.escapeHtml` 转义。
